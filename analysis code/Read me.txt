Revised manuscript analysis

Use the repository root as the R working directory.
Install packages once:
install.packages(c("dplyr", "tidyr", "ggplot2", "afex", "sft"))

Run: source("analysis code/manuscript_reproducible_analysis.R")
Input: analysis code/vst_raw_combined.csv
Outputs: output/manuscript_reproducible_analysis/
The original session-level data remain under dataset/.

Includes mean RT/accuracy analyses, order-effect sensitivity analyses,
assessment-function RT screening, pooled-trial bootstrap curves, and 500-ms
sliding windows with search-adjusted intervals. Seed 42; 10,000 replicates.
Demographic Table 1 is not generated by this script.
Existing JASP files and summary CSVs are retained as legacy materials.

Pooled-trial intervals condition on observed dyads and omit between-dyad
sampling variability. Curve bands are pointwise, not search-adjusted intervals.
The high-resolution Figure 3 under Figure/ replaces the former Figures 3 and 4.
